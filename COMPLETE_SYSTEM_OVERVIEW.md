## 🔧 Configuration

### Change Wikipedia Language
```python
from wikipedia_integration import WikipediaSearcher
wiki = WikipediaSearcher(language="en")  # English
wiki = WikipediaSearcher(language="ja")  # Japanese
```

### Custom Cache Directory
```python
wiki = WikipediaSearcher(cache_dir="/custom/path")
vocab = OnlineVocabularyManager(cache_dir="/custom/path")
```
