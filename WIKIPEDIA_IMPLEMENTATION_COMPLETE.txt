       "summary": "First 500 chars",

       "url": "Wikipedia link",
       "cached_at": "ISO timestamp",
       "source": "wikipedia"
     }
   }

🎯 COMMANDS

Wikipedia Commands:
   Apa itu [topik]              → Cari informasi
   Siapa itu [orang]            → Cari biodata
   Bagaimana cara [sesuatu]     → Cari tutorial
   cache wikipedia              → Lihat cache stats

Vocabulary Commands (masih berfungsi):
   cari arti [kata]             → Search vocab
   sinkron vocab                → Update vocab
   statistik vocab              → Vocab stats
   export vocab                 → Export vocab

Robot Commands (masih berfungsi):
   ajar                         → Teach pattern
   lihat pattern                → View patterns
   stats                        → Robot stats
